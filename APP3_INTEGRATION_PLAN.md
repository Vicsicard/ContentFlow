# App 3 Integration Plan

## Background
The ContentFlow VTT-only workflow has been successfully implemented for App 1 and App 2. App 3 integration is still failing, but we have a clear path forward to resolve these issues.

## Integration Approach

### Option 1: Direct Batch File Execution
The simplest approach is to modify our `process_app3_job` function to directly call the existing batch file:

```python
def process_app3_job(job):
    """Process a job with App 3"""
    job_id = job["id"]
    client_id = job["client_id"]
    
    try:
        # Update job status to app3
        update_job_status(job_id, "app3")
        
        log(f"Processing App 3 job for client: {client_id}")
        
        # Path to the batch file
        batch_file = r"C:\Users\digit\CascadeProjects\App 3 Content Generator Suite\new content generator 5-1-25.bat"
        
        # Create a temporary .env file with Supabase credentials
        env_path = os.path.join(APP_PATHS['app3'], ".env")
        with open(env_path, "w", encoding="utf-8") as f:
            f.write(f"SUPABASE_URL={SUPABASE_URL}\n")
            f.write(f"SUPABASE_SERVICE_ROLE_KEY={SUPABASE_KEY}\n")
        
        # Run the batch file
        result = subprocess.run([batch_file], 
                               cwd=APP_PATHS['app3'],
                               capture_output=True, 
                               text=True)
        
        # Check result and update job status
        if result.returncode == 0:
            update_job_status(job_id, "complete", "VTT-only workflow completed successfully through all apps")
            log(f"VTT-only workflow completed successfully for job {job_id}")
            return True
        else:
            error_msg = f"App 3 processing failed: {result.stderr}"
            log(error_msg)
            update_job_status(job_id, "error", error_msg)
            return False
    except Exception as e:
        error_msg = f"Error in App 3 processing: {str(e)}"
        log(error_msg)
        update_job_status(job_id, "error", error_msg)
        return False
```
